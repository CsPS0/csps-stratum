# Fastfetch Stratum (`20-shell/fastfetch`)

Custom Fastfetch system information display configuration.

## Files
- `config.jsonc`: Active compact profile displaying OS, Host, Desktop Environment, Icons, CPU, GPU, Memory, Swap, Disk, Battery, Power Adapter, Weather, and color swatches. Uses custom ASCII art Totoro logo.
- `config-full.jsonc`: Comprehensive full-detail specification with all module declarations and layout settings.
- `totoro.txt`: Custom UTF-8 Totoro silhouette artwork.
