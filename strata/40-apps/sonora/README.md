# Sonora Audio Stratum

Configuration profile for **Sonora** (v0.45.0), the modern, native music player replacing Spotify on the desktop workstation.

---

## Features & Configuration Highlights

- **Playback**: Gapless audio enabled, normalization disabled.
- **Discord Rich Presence**:
  - Live activity status with Sonora badge and provider button.
  - Show paused status enabled.
- **Synchronized Lyrics**:
  - Multi-provider fallback: Apple Music, LrcLib, Musixmatch, NetEase, Spotify, YouTube Music, Kugou.
  - Features: Karaoke mode, romanized lyrics (Japanese, Korean, Chinese, Cyrillic, Greek, Arabic), and background blur.
- **Visuals**:
  - Dark theme with ambient background motion.
  - Lucide icons with modern rounded controls.
- **Scrobbling**:
  - Last.fm integration (credentials managed out-of-band via template).
