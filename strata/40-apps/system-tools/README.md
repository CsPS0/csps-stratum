# System Management & Maintenance Stratum

Essential administrative utilities for keeping the workstation clean, optimized, and thermally stable.

---

## Utility Matrix

| Application | Primary Purpose | Deployment / Source |
|---|---|---|
| **WinDirStat** | Interactive visual treemap of disk storage | WinGet (`WinDirStat.WinDirStat`) |
| **Revo Uninstaller** | Comprehensive program uninstaller with registry trace cleanup | WinGet (`RevoUninstaller.RevoUninstaller`) |
| **HWiNFO64** | Real-time hardware telemetry and logging | WinGet (`REALiX.HWiNFO`) |
| **UniGetUI** | Consolidated GUI package manager across WinGet, Scoop & Choco | WinGet / Standalone |
| **Wintoys** | Windows 11 performance, telemetry, and system service tuning | Microsoft Store / WinGet |
| **Win11Debloat** | One-time cleanup: preinstalled apps, telemetry, ads and suggestions, Copilot/Recall | [Raphire/Win11Debloat](https://github.com/Raphire/Win11Debloat) (see `strata/10-os/windows/README.md`) |
| **SlimBrave Neo** | Strips and hardens Brave with enterprise policies (metrics, Rewards, Wallet, VPN, Leo…) | [ChaoticSi1ence/SlimBrave-Neo](https://github.com/ChaoticSi1ence/SlimBrave-Neo) (see `strata/10-os/windows/README.md`) |
| **LocalSend** | Encrypted peer-to-peer file transfer across local devices | WinGet (`LocalSend.LocalSend`) |
| **OCCT** | Power supply, GPU, VRAM & CPU stability testing | Portable Utility |
| **DDU** | Clean GPU driver removal before major driver upgrades | Portable Utility |
