# Zed Editor Stratum

Configuration profile for the high-performance [Zed editor](https://zed.dev/).

---

## Configuration Highlights

- **Theme**: `One Dark Pro Max`
- **Icon Theme**: `Material Icon Theme`
- **Keymap**: `VSCode` base bindings
- **Typography**: `JetBrainsMono NF` (UI: 16px, Buffer: 15px, Terminal: 14px)
- **Features**:
  - Bracket colorization and active indent guides
  - Inlay type & parameter hints enabled
  - Git inline blame (`delay_ms: 300`)
  - Auto-format on save with trailing whitespace removal
  - Full telemetry disabled (diagnostics, metrics, retention)
